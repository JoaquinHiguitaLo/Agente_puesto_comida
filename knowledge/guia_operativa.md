
# Guía operativa de Picanteo

**Tipo de documento:** Material de orientación académica.
**Proyecto:** Asistente inteligente Picanteo.
**Propósito:** Proporcionar información de referencia sobre la administración de pequeños negocios de comida.

> Este documento contiene recomendaciones generales elaboradas para el proyecto académico. No representa políticas oficiales ni procedimientos internos confirmados de Picanteo.

## 1. Control de inventario

El control de inventario permite conocer las existencias de productos e ingredientes utilizados en el negocio.

Se recomienda registrar las entradas y salidas de inventario, revisar periódicamente las cantidades disponibles y establecer niveles mínimos de existencias.

Cuando la cantidad disponible de un producto alcanza o cae por debajo de su stock mínimo, es recomendable revisar la necesidad de reposición.

Para consultar cantidades reales de inventario, el asistente debe utilizar la herramienta consultar_inventario.

## 2. Registro y análisis de ventas

Registrar las ventas permite conocer los ingresos por productos vendidos, identificar tendencias y apoyar la toma de decisiones.

Se recomienda registrar la fecha, el producto vendido, la cantidad, el precio unitario y el valor total de cada transacción.

El análisis de ventas puede ayudar a identificar productos con mayor demanda y periodos de mayor actividad comercial.

Para consultar cifras reales, el asistente debe utilizar la herramienta consultar_ventas.

## 3. Gestión de compras

La gestión de compras consiste en organizar la adquisición de productos e ingredientes necesarios para la operación.

Antes de realizar una compra, se recomienda revisar las existencias, las necesidades de reposición y la disponibilidad presupuestaria.

También es importante registrar las compras efectuadas para facilitar el seguimiento de los costos.

Para consultar registros reales de compras, el asistente debe utilizar consultar_compras.

## 4. Gestión de proveedores

Una buena gestión de proveedores facilita la continuidad del abastecimiento.

Se recomienda mantener información actualizada sobre los proveedores, comparar condiciones de entrega y revisar la calidad de los productos adquiridos.

El asistente puede utilizar consultar_proveedores para recuperar la información registrada.

## 5. Prevención de desperdicios

La prevención de desperdicios contribuye al control de costos y al aprovechamiento de los ingredientes.

Se recomienda revisar las fechas de vencimiento, almacenar los productos según sus necesidades y planificar las cantidades utilizadas.

Cuando sea apropiado, puede aplicarse el principio PEPS: primero en entrar, primero en salir.

## 6. Límites de la información documental

Esta guía ofrece recomendaciones generales y no contiene información actualizada sobre ventas, inventario, compras o proveedores.

Las cantidades, precios, costos, existencias y transacciones reales deben consultarse mediante las herramientas conectadas a los archivos JSON.

Si una pregunta solicita información que no aparece en esta guía ni en las fuentes disponibles, el asistente debe reconocer que no dispone de evidencia suficiente.

El asistente no debe inventar políticas, datos financieros, cantidades ni procedimientos específicos del negocio.
